# 12 · Glossário para humanos

| Termo | Em português simples |
|---|---|
| **Repositório (repo)** | Uma pasta de projeto com histórico de todas as mudanças |
| **Git** | O programa que guarda o histórico e permite voltar atrás |
| **GitHub** | O site onde os repositórios ficam guardados online |
| **Commit** | Uma "foto" salva das mudanças, com uma descrição |
| **Branch** | Uma linha paralela de trabalho que não mexe na principal |
| **Worktree** | Uma cópia de trabalho de um branch em outra pasta |
| **Pull Request (PR)** | Pedido para juntar o trabalho de um branch na linha principal |
| **Merge** | Juntar um branch na linha principal |
| **CI** | Robô que roda os testes a cada envio |
| **Staging** | Ambiente de teste, cópia da produção |
| **Produção** | O que os usuários reais usam |
| **Deploy** | Colocar a versão nova no ar |
| **Rollback** | Voltar para a versão anterior |
| **Migration** | Arquivo que descreve uma mudança no banco de dados |
| **RLS** | Regra do banco que diz quem pode ver/alterar cada linha |
| **E2E** | Teste de ponta a ponta: um robô usa o site como pessoa |
| **MVP** | A versão mínima que já vale a pena lançar |
| **API** | Porta pela qual programas conversam entre si |
| **Webhook** | Aviso que um serviço envia ao seu sistema quando algo acontece |
| **Token / chave de API** | Senha de programa. Nunca vai para o chat |
| **MCP** | Padrão que deixa a IA usar ferramentas externas |
| **Composio** | A "tomada universal" que conecta apps às IAs |
| **Gate** | Portão de aprovação (1 tarefa, 2 prova, 3 você) |
| **EARS** | Jeito de escrever critério: "QUANDO X, DEVE Y" |
| **Orquestrador** | A IA que decide, escreve tarefas e confere |
| **Executor** | A IA que escreve o código |
| **Auditor** | A IA (de outra família) que revisa |
| **QG** | A pasta-memória do seu ecossistema |
| **Checkpoint** | O arquivo "onde paramos" |
| **Prompt** | O texto que você manda para a IA |
| **Vibe coding** | Construir software dirigindo IAs, sem escrever o código você mesmo |
