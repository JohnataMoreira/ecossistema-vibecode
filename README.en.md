# Ecossistema Vibecode (English summary)

A complete, free-to-start **AI-assisted software development ecosystem for non-coders ("vibe coders")**. Primary language: Brazilian Portuguese.

**How it works:** paste one prompt into an AI that can access your computer. The AI interviews you, asks (and explains) the permissions it needs, creates the folder structure and memory files, connects your tools through a single hub (Composio), loads the accumulated lessons and then explains how you will work from there.

**The method:** a team of AIs with distinct roles (orchestrator, executors, cross-model auditor, research/visual agent), a three-gate approval flow (Gate 1 task spec, Gate 2 literal proof, Gate 3 human approval), cross-model auditing for high-risk changes, UI end-to-end tests on staging, and file-based memory (checkpoint, backlog, decision log).

**Start:** open [`PROMPT-MESTRE/PROMPT-MESTRE.md`](PROMPT-MESTRE/PROMPT-MESTRE.md). AI agents: read [`AGENTS.md`](AGENTS.md) and [`llms.txt`](llms.txt).

Also included: **Marquinhos** (an automatic social-media publisher with safeguards and alerts), **Carteiro** (comment-keyword to Instagram DM with a link, no subscription) and a single document of lessons learned.
