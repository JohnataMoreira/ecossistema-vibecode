# Caminho B — IA só de conversa (sem acesso ao seu computador)

Use este caminho se a sua IA **não consegue criar arquivos nem rodar comandos** no seu computador. É mais manual, mas funciona.

**Cole na sua IA:**

```text
Vou montar o Ecossistema Vibecode (https://github.com/JohnataMoreira/ecossistema-vibecode)
sem acesso ao meu computador. Você não pode criar arquivos, então faça assim:
1) Me pergunte meu sistema (Mac/Windows/Linux) e minha ideia de projeto.
2) Me guie para instalar Git e criar a pasta "Projetos/QG", um passo por vez, explicando cada clique ou comando.
3) Me diga para baixar o kit em https://github.com/JohnataMoreira/ecossistema-vibecode (botão Code > Download ZIP) e me explique como copiar a pasta MODELOS para dentro do QG.
4) Para cada arquivo de MODELOS, me diga quais campos {{ASSIM}} preencher e me entregue o texto final para eu colar.
5) Me explique o Composio e como conectar minhas ferramentas.
6) No fim, faça o tour: o que posso fazer e como trabalhar no dia a dia.
Nunca me peça senha ou chave no chat. Espere minha confirmação a cada passo.
```

**Dica:** assim que puder, migre para uma IA com acesso a arquivos (veja `COMECE-AQUI/00-antes-de-comecar.md`): o caminho A faz tudo sozinho.
