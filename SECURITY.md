# Segurança

## Achou algo sensível neste repositório?
Se encontrar qualquer dado pessoal, chave, token ou informação privada que não deveria estar aqui, **não abra uma issue pública**. Use o recurso *Report a vulnerability* na aba Security do GitHub (relato privado).

## Usando o kit com segurança
- Leia qualquer prompt antes de colar em uma IA com acesso ao seu computador.
- Nunca cole chaves, tokens ou senhas no chat. Veja `GUIA/08-limites-e-seguranca.md`.
- Trabalhe numa pasta dedicada e peça à IA para listar o que vai fazer antes de fazer.
- Este material é educacional e vem sem garantia.
